# Initial Data Load

This folder contains SQL scripts used to insert the initial data into the Azure SQL Database.

## Scripts

- DimCustomer_InitialLoad.sql
- DimProduct_InitialLoad.sql
- FactSales_InitialLoad.sql
- MetadataControl_InitialLoad.sql
- WatermarkControl_InitialLoad.sql

These scripts prepare the source and control tables for the Microsoft Fabric Sales & Returns Analytics solution.
